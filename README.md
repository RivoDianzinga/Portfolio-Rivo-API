# Portfolio API - Mamy Rivo DIANZINGA

Backend du portfolio personnel.

Cette API fournit les données utilisées par le frontend du portfolio.

## Frontend associé

Le frontend est disponible dans le dépôt :

- Code source : [Portfolio-Rivo](https://github.com/RivoDianzinga/Portfolio-Rivo)

- JavaScript
- Node.js
- PostgreSQL
- API REST
- Render
- Express
